WeeWX settings

WeeWX sends each archive record through its Wunderground uploader. In weewx.conf:

[StdRESTful]
    [[Wunderground]]
        enable = true
        station = {{ station.slug }}
        password = anything
        server_url = http://{{ host }}{{ ambient_path }}
Restart WeeWX afterwards. Readings arrive with each archive record.

History: import your existing WeeWX database with python manage.py import_weewx {{ station.slug }} /path/to/weewx.sdb (see Importing history from WeeWX).

The path is this station's secret. Anyone who has it can upload readings to this station, so don't share it.
